# Future ideas (deferred from Phase 1 MVP)

Ideas that **do not** serve the current north star—**~30s on-site quote**: open app → record + photos → quote → defined processes → email + SMS—get parked here instead of bloating the MVP.

## How entries get here

When you or the assistant agree an item is **not** for Phase 1, add a note:

- **Filename:** `YYYY-MM-DD-short-slug.md` (e.g. `2026-04-09-follow-up-sequence.md`)
- **Include:** what you wanted, why it was deferred, optional “revisit when”

Promote an idea back into scope by moving or referencing it in a task/issue and telling the assistant explicitly.
